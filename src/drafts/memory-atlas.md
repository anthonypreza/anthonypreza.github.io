## Idea

A personal computer vision experiment exploring whether pretrained visual
representations can reveal useful structure in photo and video collections.

## Questions to explore

- Which visual similarities do pretrained embeddings capture?
- When do clusters reflect meaningful groups rather than surface appearance?
- How should retrieval relevance and cluster coherence be evaluated?
- What changes when temporal information from video is included?

## Current state

The Python project is scaffolded. Model selection, embedding extraction,
clustering, and evaluation have not been implemented.
